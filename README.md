# yemot-currency-api

API ב-Node.js לימות המשיח, מוכן לפריסה ב-Vercel. השירות מקריא שערי מטבע בעברית, עם בחירת מטבע דרך הטלפון.

## פריסה ב-Vercel

1. פתחו את המאגר הזה ב-GitHub.
2. ב-Vercel בחרו **Add New → Project**, חברו את המאגר ולחצו **Deploy**.
3. אין צורך במשתני סביבה או במפתחות API.

## שימוש

- `/api/yemot` — תפריט בחירת מטבע.
- `/api/yemot?currency=eur` — שער האירו מול דולר אמריקאי.
- `/api/yemot?currency=ils&from=usd` — דולר לשקל.
- `/api/yemot?currency=usd&from=eur&amount=100` — המרה של 100 אירו לדולר.
- `/api/yemot?ApiPhoneInput=2` — בחירה לפי ספרה בתפריט.

קודי מטבע לדוגמה: `usd`, `eur`, `ils`, `gbp`, `chf`, `cad`, `aud`, `jpy`, `try`, `pln`, `czk`, `thb`.

## ספק שערים

הקוד משתמש במקור הציבורי של `fawazahmed0/exchange-api` דרך jsDelivr, עם גיבוי ל-Cloudflare Pages. הנתונים אינם בהכרח שער יציג רשמי של בנק ישראל.

## הערה לגבי ימות

התגובה נשלחת כטקסט UTF-8 בפורמט `read=...`. יש לאמת את תחביר הניווט מול הגדרת ה-API של ימות בחשבון שלך. ההקראה מזכירה את מקש הכוכבית; ניתוב בפועל של `*` לתפריט הראשי עשוי לדרוש הגדרת מקש/שלוחה במערכת ימות.
